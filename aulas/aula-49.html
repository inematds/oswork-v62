Chave no chaveiro, página no ar

Você consegue criar a sua chave SSH, ligar o terminal à sua conta do GitHub e pôr uma página de treino no ar, com um endereço que abre no celular.

Na aula anterior você aprendeu a conferir antes de enviar. Falta o caminho de verdade: entrar na conta sem digitar senha a cada vez, escolher quem vê e publicar. Hoje você faz isso em poucos comandos, cada um com o que conferir.

Em 1 minuto

  1. A chave privada fica no seu computador; a pública vai para o GitHub.
  2. O gh entra na sua conta e leva a chave pública numa resposta só.
  3. Público ou privado se escolhe na hora de criar; a página grátis exige público.

1A chave fica com você; o cadeado vai para o GitHub

Pense num cadeado com a sua chave. Você pode entregar cadeados a quem quiser, e só a sua chave abre. No SSH é igual. A chave pública é o cadeado. A chave privada é a chave do chaveiro.

Um comando no cmd cria as duas; o ssh-keygen já vem no Windows 10 e 11. Ele faz três perguntas: onde guardar, uma senha extra e a repetição dela. Aperte Enter nas três; sem senha extra está bem para treino. Depois, abra a pasta onde as chaves ficaram.

Lúcia criou a chave no notebook da escola e abriu a pasta. Viu os dois arquivos lado a lado e escreveu num papel qual deles nunca sai dali.

2O gh entra na conta e leva o cadeado

O gh é o GitHub dentro do terminal. Primeiro você o coloca no computador com o winget. Depois, feche e abra o cmd, para a janela nova encontrar o gh. Na primeira vez, o winget pergunta se você aceita os termos da loja: digite Y e tecle Enter. Se o Windows perguntar se o programa pode fazer alterações, clique em Sim.

Depois, o gh auth login faz o login na conta. Ele faz cinco perguntas em inglês. Cada pergunta mostra uma lista; o sinal > marca a opção da vez. Escolha com as setas ↑↓ e confirme com Enter: GitHub.com, SSH, a sua chave .pub, Enter no título e o navegador. O terminal mostra um código de 8 caracteres, como ABCD-1234: aperte Enter e digite esse código no navegador que abrir. Se ele não abrir sozinho, abra github.com/login/device no navegador. Depois do código, o GitHub pede para autorizar: clique no botão verde Authorize. Ele só dá acesso ao gh, do seu computador.

Denise fez a entrada com a conta da coordenação. Quando o gh ofereceu a chave, ela conferiu o nome: terminava em .pub. Só então confirmou.

Se travou aqui, é normalApareceu "Permission denied (publickey)" no teste? O cadeado não foi entregue. Rode gh auth login de novo e escolha SSH e a chave .pub. O gh "não é reconhecido"? Feche e abra o cmd; o winget só vale na janela nova.

3Público ou privado: você decide na hora de criar

O gh repo create cria o repositório no GitHub e faz o push da pasta de uma vez. A opção --public deixa qualquer pessoa ver. A opção --private deixa só você e quem você convidar.

A conferência da aula anterior vale aqui: destino, estado, versões e segredos. Público é para o que pode estar num mural da escola.

A página da feira de ciências da Lúcia vai para as famílias, então é pública. As notas da turma nunca entram nesse repositório.

4A página no ar com o GitHub Pages

O GitHub Pages publica a página de um repositório público. Dentro da pasta, um comando liga o serviço. Em alguns minutos o endereço abre em qualquer navegador.

Cole o comando igual, sem trocar nada: o gh preenche sozinho o {owner} e o {repo}. O endereço segue sempre o mesmo molde: o seu usuário, github.io e o nome do repositório.

Denise publicou a página de treino da coordenação e mandou o endereço para si mesma no WhatsApp. Abriu no ônibus, antes da reunião de pais.

Pratique agora 0/4

Publique uma página de treino

Pronto quando o endereço terminado em github.io/minha-pagina abrir no celular com o texto grande da sua página: Minha página de treino. Cerca de 10 minutos, no computador, com a sua conta do GitHub (crie grátis em github.com, se não tiver).

A página tem uma linha de texto, sem nenhum dado seu além do nome que você escolher. Para tirar do ar depois, apague o repositório nas configurações dele no GitHub. Não configurou nome e e-mail no Git (aula 3 deste módulo)? Rode antes: git config --global user.name "Seu Nome" e git config --global user.email "seu@email.com". Deu erro? Pare no comando que falhou e leia a primeira linha da resposta.

Bloco 1 · chave e conta, uma vez por computador. Um comando por vez: cada um faz perguntas, responda antes de colar o próximo. Depois do winget, feche e abra o cmd. No primeiro, troque <seu e-mail>, com os sinais < e >, pelo seu e-mail.

ssh-keygen -t ed25519 -C "<seu e-mail>"
winget install -e --id GitHub.cli
gh auth login
ssh -T git@github.com

Bloco 2 · a página de treino. Este pode ir inteiro: nenhum comando faz pergunta. Se o terminal avisar que o texto tem várias linhas, escolha colar mesmo assim; é normal. O curl baixa do site do curso uma página pronta, com o título Minha página de treino.

mkdir "%USERPROFILE%\projetos\minha-pagina"
cd "%USERPROFILE%\projetos\minha-pagina"
curl -fsSL -o index.html https://inematds.github.io/oswork-v62/materiais/treino/index.html
git init -b main
git add index.html
git commit -m "Primeira página"
gh repo create minha-pagina --public --source=. --push
gh api repos/{owner}/{repo}/pages -X POST -f "source[branch]=main" -f "source[path]=/"

Você acabou de ligar o seu computador à sua conta sem senha e publicou uma página que qualquer pessoa abre.

Cola da aula

Da chave à página

  1. Chave privada ficasó o arquivo .pub sai do computador.
  2. gh auth loginentra na conta e entrega a chave pública.
  3. --public ou --privatea escolha de quem vê; a página grátis pede público.

O que acontece em cada comando

ssh-keygen cria o par de chaves do tipo ed25519, o recomendado hoje pelo GitHub. O -C só põe um rótulo, normalmente o seu e-mail, para você reconhecer a chave depois.

gh auth login guarda o acesso à conta no seu computador e, com a resposta SSH, cadastra a chave pública na conta. Você confere em github.com › Settings › SSH and GPG keys.

gh repo create --source=. --push cria o repositório, liga a pasta a ele como destino e envia as versões salvas. É o mesmo que criar no site, rodar git remote add e git push.

O último comando liga o GitHub Pages a partir da linha principal, na raiz da pasta. No site, o caminho é Settings › Pages, escolha main e clique em Save.

Rotina depois de publicar

git status
git add index.html
git commit -m "Troca o título"
git push
