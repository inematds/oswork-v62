Programa novo vem da fonte oficial

Você consegue instalar o Codex pelo endereço oficial e confirmar, com um comando, que o computador o reconhece.

Na internet circulam comandos "mais rápidos" para colocar programas no computador. Um comando colado sem conferir pode executar qualquer coisa. Conferir a fonte leva um minuto e evita esse risco.

Em 1 minuto

  1. Colocar o programa, entrar com a conta e abrir na pasta são três etapas diferentes.
  2. O comando vem da página oficial. Confira o endereço antes de colar.
  3. codex --version confirma que deu certo.

1Três etapas, uma de cada vez

Instalar põe o programa no computador. Isso não conecta a sua conta nem escolhe a pasta de trabalho. Cada coisa tem a sua etapa e a sua conferência.

Esta aula faz só a primeira. As outras duas vêm nas aulas 15 e 16.

Logo depois de instalar, Lúcia digitou codex e o programa pediu para ela entrar com a conta. Achou que era defeito. Não era: a primeira etapa tinha dado certo, e faltava a segunda.

2Confira o lacre antes de abrir a caixa

Quando chega uma caixa na secretaria, você olha o lacre e o remetente antes de abrir. Com um comando é igual: o remetente é o nome do programa que ele pede.

No Windows, quem instala é o winget, que já vem no sistema. Primeiro ele põe o Node.js. Depois, o npm, que vem com o Node.js, baixa o Codex pelo nome oficial @openai/codex. Comando de página desconhecida não se cola.

Denise recebeu num grupo um "jeito mais rápido" de pôr o Codex no computador. O nome no meio do comando não era @openai/codex. Ela não colou e usou o da página oficial.

3Cole os dois comandos e espere cada um terminar

Abra o cmd e cole um comando de cada vez. O primeiro instala o Node.js; o segundo, o Codex. Use o botão copiar. Entre os dois, feche o cmd e abra de novo: só a janela nova enxerga o programa que acabou de chegar.

Na primeira vez, o winget pode perguntar se você aceita os termos da loja. Digite Y e tecle Enter. As linhas que passam você não precisa entender. Espere o > voltar. Quem confirma se deu certo é o passo 4.

Lúcia colou o primeiro comando e esperou a mensagem "Instalado com êxito". Fechou o cmd, abriu outro e colou o segundo.

4codex --version confirma

Para saber se deu certo, peça a versão. Se o computador reconhece o programa, ele responde com um número.

Se aparecer "não é reconhecido como um comando interno ou externo", o cmd ainda não achou o programa. Feche o cmd, abra de novo e repita.

No notebook de Denise, a primeira tentativa deu "não é reconhecido". Ela fechou o cmd, abriu outro e digitou de novo. Veio o número da versão.

Se travou aqui, é normal"Não é reconhecido" logo depois de instalar é comum: o cmd aberto antes não sabe do programa novo. Feche, abra de novo e repita o codex --version. O npm também não é reconhecido? O Node.js não terminou de instalar: repita o primeiro comando. Continuou? Copie a mensagem de erro, sem senha nenhuma, e leve para quem cuida do computador.

Pratique agora 0/3

Coloque o Codex no computador e confira a versão

Pronto quando codex --version responder com um número. Cerca de 10 minutos, no computador, com internet.

Os comandos só valem se os nomes forem iguais aos da página oficial: OpenJS.NodeJS.LTS e @openai/codex. Se o Windows perguntar se o programa pode fazer alterações e o computador é seu, clique em Sim. Se o computador é da escola, pare e fale com quem cuida dele.

Passo 2 · cole no cmd

winget install -e --id OpenJS.NodeJS.LTS

Passo 3 · feche, abra outro cmd e cole

O que é

A página oficial do Codex indica o pacote @openai/codex, instalado pelo npm, que vem com o Node.js. Instalar significa adicionar o programa à máquina. Leia a fonte, confira o nome do pacote e use sua própria conta. Não execute comandos recebidos de páginas desconhecidas.

Por que aprender

Instalação, login e execução são etapas diferentes. Um programa instalado ainda precisa de autenticação. Um login concluído não significa que você abriu a pasta correta.

Conceitos-chave

Fonte oficial; instalação; versão; diagnóstico.

Na prática

Depois da instalação, codex --version informa a versão reconhecida pelo cmd. Se aparecer "não é reconhecido como um comando interno ou externo", feche e abra o cmd. Persistindo, confira se node --version e npm --version respondem.

Experimente agora

No cmd: winget install -e --id OpenJS.NodeJS.LTS; feche e abra o cmd; npm install -g @openai/codex. Depois verifique com codex --version.
